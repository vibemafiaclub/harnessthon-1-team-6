# 01 — 디자인 시스템

> 출처: Penpot 파일 `작업_하이서` / Page **`1-daangn`** 의 `당근마켓_1`~`당근마켓_5` 보드 5개
> 추출 방법: 보드 하위 **847개 shape를 순회**해 fills·strokes·타이포·지오메트리를 빈도 집계
> 이 문서의 모든 값은 레퍼런스에서 **실측**한 것입니다. 레퍼런스에 없는 값은 "출처 없음"으로 표시했습니다.

## 토큰 (JS 상수 — 저작 코드에 그대로 복사해서 사용)

```js
const TOKENS = {
  color: {
    // 브랜드
    primary: "#FF7E36", // 가격 텍스트, CTA 버튼
    primaryTint: "#FFEBE0", // 아이콘 배경 등 연한 브랜드 면

    // 배경 / 면
    bg: "#FFFFFF", // 화면 기본 배경
    surface: "#F6F6F6", // 작은 썸네일 자리
    surfaceAlt: "#F4F4F4", // 원형 아바타 플레이스홀더

    // 텍스트 (위계 순)
    text: "#000000", // 제목·본문
    textSecondary: "#8C8C8C", // 메타정보(지역·시간·조회수)
    textTertiary: "#5E5E5E", // 보조 설명
    textOnPrimary: "#FFFFFF", // 브랜드 면 위 글자

    // 선
    border: "#EEEEEE", // 구분선 기본
    borderStrong: "#D9D9D9", // 강조 구분선·비활성 요소

    // 지표 전용 (희소)
    accent: "#4AC1DB", // 매너온도류 게이지. 남용 금지

    // 출처 없음 — 레퍼런스에 위험/경고 색이 존재하지 않음.
    // 필요해지면 아래 제안값을 쓰되, 쓴 사실을 4단계 산출물에 기록할 것.
    danger: "#E5503C", // (제안값, 레퍼런스 미검증)
  },

  font: {
    family: "Pretendard", // 한글 본문·제목. Inter는 한글 글리프가 없음
    familyLatin: "Inter", // 숫자·영문 전용 (레퍼런스 실사용 폰트)
    weight: { regular: 400, bold: 700 }, // 레퍼런스에 이 둘만 존재

    // 크기 (레퍼런스 사용 빈도 순)
    h1: 18, // 지역명·섹션 제목 (700)
    h2: 16, // 상품명·항목 제목 (400)
    price: 15, // 가격 (700, primary 색)
    body: 14, // 본문
    bodySm: 12, // 최다 사용. 메타정보·리스트 보조행
    caption: 10, // 탭바 라벨·뱃지

    // 행간 (배수) — 크기별 실측값
    lineHeight: {
      h1: 1.4,
      h2: 1.25,
      price: 1.47,
      body: 1.29,
      bodySm: 1.33,
      caption: 1.4,
    },
  },

  space: { xxs: 2, xs: 4, sm: 8, md: 12, lg: 16, xl: 24 },
  gutter: 16, // 화면 좌우 고정 여백. 390 화면에서 콘텐츠 폭 = 358

  radius: {
    sm: 4, // 썸네일·카드 기본
    md: 8,
    lg: 24, // 알약형 작은 칩
    full: 100, // 원형 아바타·플로팅 버튼
  },

  screen: { w: 390, h: 844 }, // 레퍼런스 보드 규격
};
```

## 🔴 폰트 규칙 (어기면 조용히 깨집니다)

`penpot.fonts.all` (1912개) 로 실재 여부를 확인한 결과입니다.

| 폰트          | 서버 존재   | 조치                                               |
| ------------- | ----------- | -------------------------------------------------- |
| `Inter`       | ✅ 있음     | 숫자·영문에 사용                                   |
| `SF Pro Text` | ❌ **없음** | **쓰지 말 것.** 지정해도 조용히 대체됨 (에러 없음) |
| `Pretendard`  | ✅ 있음     | **한글 기본 폰트로 확정**                          |

- 레퍼런스는 텍스트가 전부 한글인데 `Inter`(211회)로 지정돼 있습니다.
  **Inter에는 한글 글리프가 없어** 렌더러가 대체 중이며, 그대로 따라 하면 새 화면에서도 같은 문제가 재발합니다.
- 따라서 **한글이 포함된 모든 텍스트는 `Pretendard`** 를 명시하세요.
  대안: `Noto Sans KR`, `Gothic A1`, `IBM Plex Sans KR` (모두 서버 존재 확인)
- 폰트를 새로 쓰기 전에는 반드시 `penpot.fonts.all` 로 존재를 먼저 확인하세요.

## 적용 규칙 (3·4단계용)

1. **색은 위 11개 토큰만 씁니다.** 중복 회색(`#DADADA` 등)을 새로 도입하지 마세요.
2. `primary`는 **가격과 주요 CTA에만**. 면으로 크게 깔지 않습니다 — 레퍼런스는 항상 작은 면적입니다.
3. `accent`(`#4AC1DB`)는 **지표 하나에만**. 847개 중 2회 쓰인 색입니다.
4. 좌우 여백은 항상 `gutter`(16). 390 화면의 콘텐츠 폭은 **358**입니다.
5. fills는 **penpot 형식** `{ fillColor: TOKENS.color.x, fillOpacity: 1 }` 로 씁니다.
   figma 형식(`{type:"SOLID", color:{r,g,b}}`)을 쓰면 인스턴스 오버라이드가 막힙니다.
6. 색 문자열은 **대문자 hex** 입니다 (`#FF7E36`). Penpot API 요구사항입니다.

## 재현 방법

이 문서는 아래로 재생성할 수 있습니다 (하드코딩된 결과가 아닙니다).

1. `penpot.currentFile.pages` 에서 레퍼런스 Page를 이름으로 찾는다. **`openPage`를 쓰지 않는다** — 읽기 전용.
2. 레퍼런스 보드의 자식 트리를 재귀 순회하며 `fills[].fillColor`, `strokes[].strokeColor`,
   `fontFamily/fontSize/fontWeight/lineHeight`, `borderRadius` 를 빈도 집계한다.
3. 오토레이아웃이 없으면 `gap`·`padding`이 비므로, 형제 shape의 `y + height` 차이와
   보드 기준 `x` 오프셋으로 스페이싱을 실측한다.
4. `penpot.fonts.all` 로 폰트 실재를 확인하고 대체 폰트를 확정한다.
5. 빈도 상위값을 역할별로 명명해 `TOKENS`로 고정한다.
