# 01 — 디자인 시스템

> 출처: Penpot 파일 `최종제출_6팀` / Page `3-toss` 의 보드 4개 — `홈`(자산 요약) · `혜택` · `전체`(전체 메뉴) · `설정`(상세)
> 추출 방법: 보드 하위 **452개 shape**(board 225 · text 94 · path 69 · rectangle 33 · ellipse 21 · group 10)를 플러그인 코드로 재귀 순회해 빈도 집계. 스페이싱은 flex 레이아웃 실값 + 지오메트리 실측 병행.

## 토큰 (JS 상수 — 저작 코드에 그대로 복사해서 사용)

## 적용 규칙 (3·4단계용)

- 색은 위 토큰만 사용. 흡수된 중복값·희소 일러스트색을 다시 도입하지 않는다.
- fills는 **penpot 형식** `{ fillColor, fillOpacity }` — figma 형식은 인스턴스 오버라이드가 막힌다.
- 색 문자열은 **대문자 hex** (Penpot API 요구사항).
- 좌우 여백은 항상 `gutter`(22). 콘텐츠 폭 = `screen.w - gutter*2` = **346**.
- 폰트는 전 텍스트 `Noto Sans KR` + weight 400/500/700만. lineHeight 1.2 고정.
- **다크 테마가 기본이다.** 밝은 배경 화면을 만들지 않는다.
- `danger`는 실패·마감 상태 전용 — 사용하면 그 사실을 산출물에 기록한다.

## 레퍼런스 관찰 노트 (반복 패턴 — 3단계 컴포넌트 설계 참고)

- **리스트 행 (ListRow)**: `[원형 아이콘(ellipse+path) | 텍스트 스택 | (우측 액션)]` 가로 flex, columnGap 13~15, 상하 패딩 6~8, 좌우 22. `설정`·`전체` 보드의 지배적 패턴.
- **자산 카드 (AssetCard)**: bgCard(#1F2026) + radius 20 컨테이너 안에 ListRow 반복. 각 행 = `[은행 아이콘 | 계좌명 12px textBody + 금액 16px 700 textPrimary | "송금" 칩]`. 칩 = bgChip + radius 6 + 12px 400.
- **혜택 행 (BenefitRow)**: `[원형 일러스트 아이콘 | 15px 500 textBody 제목 + 13px primary CTA("OO 받기")]` — CTA가 버튼이 아니라 **파란 텍스트 링크**인 것이 이 디자인의 문법.
- **섹션 헤더**: 20px 700 textStrong 단독 행, 아래 콘텐츠와 세로 20 간격.
- **하단 탭바 (TabBar)**: 5탭 고정 `[아이콘 + 10px 레이블]`, 활성 = textStrong, 비활성 = textSub. 탭바 높이 60 + 하단 홈 인디케이터 영역 77.
- **상태바**: 높이 36, "9:41" 17px 400. 화면 최상단 고정.
- **배지**: 11px 500 accent(#EDA54B) 텍스트 단독 — 배경 없는 텍스트 배지.
- 레퍼런스의 프레임 이름은 `Frame 5` 식으로 무의미 — **신규 저작에서는 의미 기반 이름을 쓴다** (레퍼런스의 이 부분은 따라 하지 않는다).

## 재현 방법

1. `penpot.currentFile.pages`에서 이름 `3-toss`로 Page를 찾는다 (openPage 없이 읽기만 — 전환 금지).
2. Page 직속 자식 중 390×844 board 4개(`홈`·`혜택`·`전체`·`설정`)를 순회 대상으로 삼는다.
3. 플러그인 코드 안에서 재귀 순회하며 집계만 반환한다: 텍스트/면 fillColor 분리 빈도, strokeColor·fontFamily·fontSize·fontWeight·lineHeight·borderRadius 빈도, 텍스트 `characters` 전량(카피 코퍼스).
4. flex 레이아웃의 gap·padding 실값과 지오메트리 실측(`다음.y - (이전.y+이전.height)`, `자식.x - 보드.x`)으로 스페이싱을 구한다. 좌측 여백 최빈값 = 거터.
5. `penpot.fonts.all`에서 레퍼런스 폰트 존재·한글 글리프를 확인하고 대체 폰트를 확정한다.
6. 빈도·역할 기준으로 토큰을 명명하고 근접 중복을 흡수해 기록한다.
