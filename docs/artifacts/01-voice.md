# 01 — 보이스 & 카피 규칙

> 이 문서는 **4단계(화면 조합)가 화면의 모든 텍스트(레이블·더미 데이터·상태 문구)를
> 쓸 때 읽는다.** 시각 토큰은 여기 없다 — `01-design-system.md`를 볼 것.
>
> 브랜드 식별: PRD 1절 "금융 앱을 만들어 온 팀" + 레퍼런스 카피("토스뱅크", "토스페이", "토스프라임") → **토스(Toss)** 스타일.
> 증거: `3-toss` Page의 카피 코퍼스 94건. 웹 조사는 가설 보강용 — 코퍼스로 확인된 것만 규칙으로 승격했다.

## VOICE (JS 상수 — 더미 텍스트·레이블 작성 시 그대로 따른다)

```js
const VOICE = {
  brandEssence: "어려운 금융(→여행)을 쉽고 친근하게 — 사람이 말하는 것 같은 문장", // 토스 UX 라이팅 공식 원칙 + 코퍼스 부합
  persona: ["친근한", "간결한", "능동적인", "구체적인"],
  어미: "~해요체", // 완성 문장은 전부 해요체. 예: "홍길동님, 투표권이 생겼어요"
  레이블: "명사형 또는 '~하기/~받기/~보기' 동명사형 1~4어절", // "송금", "잔액보기", "결제지원금 받기", "내 정보 수정하기"
  버튼레이블: "동사 어간+기, 2~4어절, 사용자가 얻는 것 중심", // "130원 받기", "추가 혜택 보기", "얼마 받을 지 보기"
  숫자표기: "천 단위 콤마 + 단위 붙임, 숫자가 문장의 주인공", // "3,820 원", "새 내역 9건", "9시간 남음", "130원 받기"
  호칭: "'OO님' — 이름+님으로 부른다", // "홍길동님, 투표권이 생겼어요"
  긴박표기: "남은 시간·기한은 사실만 담백하게", // "9시간 남음" — 느낌표·서두름 강요 없음
  금지표현: [
    "명령형·강요 (예: '지금 확인하세요!')",   // 코퍼스에 명령형 0건 + 토스 'Suggest over force' 원칙
    "느낌표·과장·공포 조성",                    // 코퍼스에 느낌표 0건
    "전문용어 단독 노출",                        // 토스 'Easy to speak' — 코퍼스도 일상어만
    "의미 없는 수식어 ('다양한', '편리한' 등)", // 토스 'Weed cutting' — 코퍼스 문장 전부 핵심어만
    "유행어·은어·밈",                            // 토스 'Universal words'
  ],
};
```

## 규칙별 근거

| 규칙 | 출처 | 근거 (카피 예시 또는 URL) |
| --- | --- | --- |
| 어미 = 해요체 | `양쪽 일치` | 코퍼스: "홍길동님, 투표권이 생겼어요" / 웹: "모든 문구는 '해요체'로" (토스 공식) |
| 레이블 = 명사형·동명사형 1~4어절 | `파일 관찰` | "송금", "잔액보기", "마이데이터 자산 연결", "홈 화면 설정" — 94건 중 완성 문장은 1건뿐, 나머지 전부 짧은 명사구 |
| 버튼/CTA = "~받기/~보기/~하기", 이득 중심 | `파일 관찰` | "결제지원금 받기"(2), "포인트 받기"(2), "130원 받기", "추가 혜택 보기", "얼마 받을 지 보기", "투표하기" |
| 숫자 = 콤마 + 단위, 해석 가능한 구체값 | `양쪽 일치` | 코퍼스: "3,820 원", "새 내역 9건", "9시간 남음" / 웹: 구체적 사례·숫자로 설명 (토스 UX Writing) |
| 호칭 = "OO님" | `파일 관찰` | "홍길동님, 투표권이 생겼어요" |
| 긴박함은 사실만 ("N시간 남음") | `양쪽 일치` | 코퍼스: "9시간 남음" (느낌표·경고 톤 없음) / 웹: 'Suggest over force' — 공포감 없이 권유 |
| 명령형·느낌표 금지 | `양쪽 일치` | 코퍼스 94건에 명령형·느낌표 0건 / 웹: 'Suggest over force' |
| 능동형 문장 | `웹` (참고) | 토스 공식 원칙이나 코퍼스에 완성 문장이 적어 직접 검증 불가 — 참고로만 |
| 'Find hidden emotion' (감정 공감) | `웹` (참고) | 토스 8원칙 중 하나 — 코퍼스에서 미확인. 상태 문구(빈 상태 등) 작성 시 참고만 |

## 4단계 적용 지침 (여행 도메인 번역 예)

- 항공권 CTA: "최저가 보기", "이 가격에 담기", "알림 받기" (○) / "지금 예약하세요!" (×)
- 가격 하락 알림: "담아둔 오사카, 32,000원 내렸어요" — OO님·해요체·구체 숫자
- 마감 표기: "오늘 자정 마감", "3자리 남음" — 사실만, 느낌표 없음
- 빈 상태: "아직 담아둔 목적지가 없어요" + 다음 행동 제안 1개
- 로딩: "실시간 요금을 불러오고 있어요"
